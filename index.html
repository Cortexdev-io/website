Cortex Financial Engine · Em desenvolvimento

Conciliação financeira sem o caos das planilhas.

Transforme extratos de diferentes corretoras em posições padronizadas, divergências verificáveis e relatórios claros. Claude interpreta documentos; nosso motor confere os números.

O problema que o produto resolve

Formatos incompatíveis

Cada corretora ou custodiante envia o extrato de um jeito: CSV, planilha, PDF ou e-mail.

Consolidação manual

Alguém copia os números para uma planilha e refaz as contas à mão.

Totais que não batem

Quando o total declarado difere da soma das posições, achar a origem consome horas.

Pouca rastreabilidade

Sem a linha de origem, ninguém sabe de onde veio cada valor.

Como funciona o Cortex Financial Engine

  1. 1Importar

    Extratos em CSV, planilha ou e-mail entram no mesmo fluxo.

  2. 2Interpretar e padronizar

    Formatos regulares são lidos por código. Texto livre é interpretado pelo Claude.

  3. 3Validar e conciliar

    O código soma, refaz quantidade × preço médio e compara com o total declarado.

  4. 4Revisar e exportar

    Divergências viram exceções para uma pessoa decidir. A exportação é em CSV.

Hoje, em código e com testes

Leitura de CSV e XLSX no formato brasileiro, totais com precisão decimal, conferência que reproduz a divergência de R$ 600,00 da demonstração e exportação CSV protegida contra injeção de fórmulas. Roda localmente, com dados fictícios.

Simulado

A interface do provedor de IA existe, mas hoje responde com um provedor simulado. Nenhuma chamada à API do Claude é feita pelo motor.

Ainda não existe

Leitura de PDF, integração com a API do Claude, aplicação web com login, envio de arquivos de clientes e piloto aberto.

Segurança e privacidade

  • A demo usa apenas dados fictícios.
  • Chaves de API ficam no servidor, nunca no navegador nem em repositório.
  • Pedimos só os arquivos e campos necessários ao projeto, combinados antes.
  • Acessos de clientes com permissão mínima (somente leitura sempre que possível), revogados ao fim do projeto.
  • Dados do cliente são apagados ao fim do projeto ou conforme combinado por escrito.
  • Os resultados passam por validação em código e, quando combinado, por revisão humana.
  • Os documentos enviados ao Claude são processados pela API da Anthropic, conforme os termos comerciais dela, o que pode envolver processamento fora do Brasil.

Perguntas frequentes

O Cortex Financial Engine já está à venda?

Não. É um produto em desenvolvimento, ainda sem preço nem plano de assinatura. Os valores desta página são de projetos sob medida.

O que já funciona hoje?

Uma demonstração gravada com dados fictícios e um motor de conferência em código, com testes automatizados, que lê CSV e planilhas e reproduz a divergência de R$ 600,00 da demonstração. A integração com a API do Claude e o envio de arquivos de clientes ainda não existem.

Como participo do piloto?

Escreva pelo WhatsApp ou por e-mail. O piloto será limitado e, no começo, usará apenas arquivos de exemplo ou fictícios.

Onde vão meus dados?

Seguem a política de segurança acima: só o necessário, processados no ambiente do projeto e pela API da Anthropic, apagados ao fim conforme combinado.

Funciona com os meus formatos?

Funciona com CSV, planilhas, PDFs com texto e e-mails. PDFs digitalizados avaliamos caso a caso. Mande um exemplo na conversa.

O Claude pode errar?

Sim. Por isso há validação por código (totais, tipos, duplicidades), campos de dúvida sinalizados e revisão humana antes de uso em decisões.

Vocês dão recomendação de investimento?

Não. A Cortex Dev organiza e apresenta dados; não recomenda investimentos.

Quanto tempo leva um projeto sob medida?

Primeira versão funcional em até 72h após alinharmos o escopo e recebermos os acessos necessários.

Posso cancelar?

Sim. Não há contrato longo, e o acompanhamento mensal é opcional e pode ser cancelado quando quiser.

Preciso instalar algo?

Em geral não. Combinamos o formato da entrega no escopo.

O código é meu?

Combinamos por escrito no escopo. A regra padrão é que o que for desenvolvido para o seu projeto é entregue a você, com documentação.
