Política de Privacidade

Atualizada em 7 de outubro de 2026.

Quem é o responsável

O responsável pelo tratamento dos dados é Bruno Carvalho Pessoa, da Cortex Dev. Contato: contato@cortexdev.io. Esta política segue a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

Quais dados coletamos

Apenas o que você nos envia por WhatsApp e e-mail, como nome, telefone, e-mail e o conteúdo das mensagens. Se houver projeto, também os arquivos que você optar por enviar. O site não tem formulários.

Para que usamos

Para responder ao seu contato e, havendo projeto, para executá-lo.

Com quem compartilhamos

Usamos provedores de infraestrutura para operar o site e o atendimento:

  • Cloudflare, para hospedagem do site.
  • Hostinger, para e-mail.
  • WhatsApp, para conversas.
  • Google Fonts, para carregar as fontes do site.
  • Em projetos, a API da Anthropic, que processa os documentos enviados ao Claude.

Esses serviços podem envolver processamento de dados fora do Brasil.

Por quanto tempo guardamos

Os dados do cliente são apagados ao fim do projeto ou conforme combinado por escrito.

Seus direitos

Você pode pedir confirmação do tratamento, acesso, correção, anonimização, portabilidade, eliminação dos dados e informações sobre compartilhamento, entre outros direitos previstos na LGPD. Para exercê-los, escreva para contato@cortexdev.io.

Segurança

  • Chaves de API ficam no servidor, nunca no navegador nem em repositório.
  • Pedimos só os arquivos e campos necessários ao projeto, combinados antes.
  • Acessos de clientes têm permissão mínima (somente leitura sempre que possível) e são revogados ao fim do projeto.
  • Os resultados passam por validação em código e, quando combinado, por revisão humana.

Cookies

O site não usa cookies de rastreamento nem ferramentas de análise.

Demonstração

A página de demonstração usa apenas dados fictícios.
