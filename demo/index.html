O que o Claude faz e o que o código faz

Claude

Lê e redige

Lê os três arquivos e devolve os dados no formato único. No fim, escreve o resumo e responde perguntas a partir dos números já calculados.

Código

Confere e calcula

Compara totais, refaz quantidade × preço médio de cada linha e consolida a posição por ativo, corretora e setor fictício.

Stack

  • Claude para leitura e resumo.
  • JavaScript para conferência e cálculos.
  • Página estática.

A leitura dos arquivos foi feita pelo Claude dentro de uma página de demonstração. Os resultados mostrados são de uma execução real com dados fictícios. Em projetos, combinamos o formato da entrega no escopo.
